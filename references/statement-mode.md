# Working from a statement

A statement may provide a conclusion with little supporting reasoning. Distinguish what it asserts from the premises it would need.

## Match the requested size

For one named standard, write or explain that standard only. For several requested paragraphs, follow the requested standards and order. For a full critique, choose an argument structure suited to the question and brief. If the user simply asks for a PEEL paragraph, do not expand it into an essay.

A standalone paragraph still links back to the statement. It does not need an introduction, conclusion or all eight elements.

## Find the inferential issue

Identify the conclusion, key concepts and any implied condition needed for the claim. Words such as “always” or “eliminate” can make the claim stronger than the available support. Do not infer a speaker's identity, intention or vested interest from the statement alone.

For “Autonomous vehicles will eliminate road accidents”, a logic analysis can ask whether eliminating one source of accidents is sufficient to eliminate all accidents. This is a reasoning question. Claims about actual collision rates would need evidence. A hypothetical failure case must be labelled as hypothetical.

## Use sources appropriately

If the user supplies evidence, evaluate what it supports. If the task needs external facts and allows research, retrieve suitable sources and retain their links. Do not search merely to decorate a conceptual explanation with citations.

If research is unavailable or the user requests only the supplied text, analyse the concepts and inference at that scope. Explain what remains unresolved. Do not substitute a remembered statistic, a guessed paper or a fictional citation.

When asked to argue for or against a statement, support the requested position without concealing material contrary evidence. If the available evidence only supports a narrower position, explain that limitation.

## Review

Check that the paragraph evaluates the intended statement rather than a stronger or weaker substitute. Distinguish the assertion “the passage provides no evidence” from “there is no evidence”. Preserve the exact requested word limit.
