# README artwork

New artwork for NUS Skill Issue by Skill Issue Labs, created on 12 October 2026 with OpenAI's built-in image generation tool.

| File | Dimensions | Purpose |
| --- | --- | --- |
| [nus-skill-issue-banner.png](nus-skill-issue-banner.png) | 1774 × 887 | README banner |
| [es2631-workflows.png](es2631-workflows.png) | 1634 × 962 | Task selection infographic |

The user's Overkill banner and effort table were inspected as visual references. The new artwork carries forward the warm ivory paper, dark ink, vermilion accent, editorial serif headings, engraved mechanical illustration and Skill Issue Labs footer. The academic optical drafting instrument and module content were newly generated. No reference pixels were manually composited into these files.

The banner was generated in one call. The workflow sheet was generated in one call and refined with two targeted image edits to replace decorative handwriting with abstract rules and remove accidental lettering from the instrument. Both final files were inspected for wording, readability, composition and branding. The workflow information is also provided as accessible text in the main README.

The complete generation and editing prompts are in [generation-prompts.md](generation-prompts.md). These assets are included under the repository's [MIT licence](../LICENSE) to the extent they are licensable. The illustrations do not contain an official NUS crest or university logo and do not indicate university endorsement.
